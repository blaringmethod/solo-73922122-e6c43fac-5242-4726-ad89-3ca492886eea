# 期货连续合约结算价系统

把多个合约的期货结算价，按固定换月计划统一到**指定基准日的连续合约口径**。
Flask + SQLite 单体应用，Docker Compose 一键启动。

## 口径定义

- 合约序列：一个**初始合约**（`ord=0`）+ 每次换月启用的新合约（第 k 次换月 → `ord=k`）。
- 换月价差：取**切换日前一交易日**的 `新合约结算价 − 旧合约结算价`（单位：整数分）。
- 某日 d 的连续价（基准日 B，B 不早于查询结束日）：

```
连续价(d, B) = 当日在用合约结算价
             + Σ { 各次换月价差 | d < 切换日 <= B }
```

- 当日原价缺失 → 连续价留空，注明缺哪个合约哪天的原价。
- 区间内某次换月缺报价 → 连续价留空，注明**最早**缺价换月及其待补的合约/日期。
- 连续价**实时计算、不落库**；改价不逐日回写。

## 缺报补数：交易所价差表与推算价

合约缺报结算价时，行情员可用交易所**同日公布的合约价差**补数（报价页「交易所价差表」）：

- 按交易日**保存、替换或清空**价差表；每行填两个**已登记**合约代码与
  **后者减前者的整数分价差**（`price(B) − price(A)`）。
- 能经价差连起来的合约按**连通组**核对（带权并查集维护相对价）：
  - 组内**至少一笔实报**，且全部实报与价差**能同时成立**（无矛盾），
    才推算缺报合约的结算价；
  - **无实报**或**有矛盾**的组撤下推算价并提示原因，**实报照用**；
  - 价差表本身可照常保存。
- **实报永远优先于推算价**：同值实报补录后自动替代推算价，来源标记切回实报。
- 取价口径（当日在用合约价、换月价差两条腿）：实报优先，实报缺失时取同日成立的推算价。
- 补改实报或换表时，**只重算当天**的推算价和引用该日报价的换月（`pre_date` 唯一，至多 1 次），
  其他交易日不触碰。
- 输入（实报/价差表）、推算结果、换月价差及其 Fenwick 索引在**一个 `BEGIN IMMEDIATE` 事务**内
  一同生效；保存失败整体回滚、照旧供数，预期结果仍随返回值可供展示。
- 连续价网页与 CSV 从**同一已提交快照**取实报和可用推算价，保留缺价提示，
  并逐日标明**结算价**与**换月调整**是否用了推算价（CSV 含「原价来源」「换月调整含推算价」两列）。

## 数据结构与复杂度

| 表 | 作用 |
|---|---|
| `calendar` | 交易日历 |
| `contracts` | 初始合约及每次换月启用的合约（`ord` 即启用次序） |
| `rolls` | 固定换月计划：切换日、前一交易日、新合约、价差（缺报价为 NULL）、`roll_inferred` 标记 |
| `prices` | 按合约 + 交易日登记的整数分**实报**结算价（联合主键，重复提交即更正） |
| `spreads` | 按交易日全量替换的交易所价差表（`B − A`，整数分） |
| `inferred_prices` | 当天推算价：`ok` 可用；`no_anchor`/`conflict` 为撤下记录并附原因 |
| `bit_sums` | 换月价差的 **Fenwick 树**辅助表 |

- 价差区间求和、单点更新均为 **O(log n)**（n=换月次数）；辅助记录数 ≤ n，随换月次数只对数级增长。
- 单笔实报/价差表更新：写业务行 + 当天推算重算（仅当天合约数）+ 至多重算 1 个价差 +
  Fenwick 单点 O(log n)，单事务原子提交。
- 单日查询所读换月及索引记录数至多随换月次数按**对数增长**：在用合约定位走 `switch_date`
  唯一索引反向定位，区间价差走 Fenwick，推算标记走部分索引/`ord` 主键的 `LIMIT 1` 探测。
- 一次取数在一个只读快照事务内完成，只看到同一已提交状态（SQLite 读快照）。

## 快速开始（Docker Compose）

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

数据库持久化在宿主机 `./data/continuous.db`（含 WAL 文件）。旧版本库启动时自动补列迁移，
历史报价与换月数据保留。

## 本地运行（无 Docker 时）

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export CONT_DB_PATH=$(pwd)/data/continuous.db
python -m flask --app app.app run --host 0.0.0.0 --port 8000
```

## 使用流程

1. **交易日历**：每行一个 `YYYY-MM-DD`，全量替换保存。
2. **换月计划**：填初始合约代码，逐行添加「切换日 + 当日启用的新合约」后保存。
   切换日必须在交易日历内且严格递增；已有报价/价差表后禁止整体重建（防历史错配）。
3. **报价补录/更正**：选合约、交易日，填整数分价格。重复提交即更正；也可撤下一笔实报。
   保存同事务自动联动重算当天推算价与受影响换月价差。
4. **价差表补数**：选交易日，逐行填「合约 A、合约 B、B−A 整数分价差」后保存/替换/清空；
   页面同时展示当天推算结果（成立、无实报撤下、矛盾撤下及原因）。
5. **连续价取数**：选开始日、结束日、基准日（不得早于结束日）→ 查询 / 下载 CSV
   （UTF-8 BOM，Excel 直开不乱码；缺价行连续价列留空并附说明，逐日标注推算价使用情况）。

```bash
  python tests/e2e_http.py
```
